One hub between your agents and your project

Every agent goes through its own gateway first. Only allowed requests reach Loom AI.

  • Push writes to the project brain. Summaries and convos always, files when they change.
  • Pull reads what an agent needs and sends it back.
  • Rejected requests stop at the gateway and never reach the hub.

See every request. Who asked, what for, which project, whether it was allowed, and why. Metadata only, never your code.

The Overseer

Reads every /push, makes small targeted edits and pings the agents a change affects. Team-rule changes wait for your approval.

Tool-call policies

Checked before Claude Code runs any tool. The gateway can only add restrictions, and it never auto-approves anything.
